# 소스 파서와 표본

`fixtures/*.html`은 2026-09-25~26 공개 페이지의 DOM 조사에서 확인한 선택자·ID·구조를 최소 형태로 옮긴 **축약 표본**입니다. 라이브 응답 전체를 그대로 저장한 자료가 아니며 회사명·본문 일부는 테스트용입니다. 근거: `docs/research/phase-1-dom-deep-dive-2026-09-26.md`.

- 사람인: 추천 블록과 실제 목록 구분, `rec_idx`, 한 문서에 다른 공고 상세가 함께 붙는 구조, 본문 iframe, 날짜·상태.
- 잡코리아: `gno`와 `gino` 구분, 자바스크립트 페이지 이동, JSON-LD 식별자, 본문 iframe, 추천 공고의 마감 문구 배제.
- 인크루트: `ul.c_row[jobno]` 한 건과 `li.c_col` 셀 구분, 필터를 보존하는 다음 링크, 접수 기간·근무 지역, 접수 영역 없는 제휴 마감 템플릿.

본문 이미지 변경·본문 실패·재오픈 등 상태 전이는 테스트에서 입력을 명시적으로 바꿉니다. 라이브 검증은 별도의 수동 CLI 실행이며 테스트 수와 섞어 주장하지 않습니다. 상세 선택자가 바뀌면 성공으로 비워 저장하지 말고 파서 실패 또는 부분 추출로 반환합니다.
